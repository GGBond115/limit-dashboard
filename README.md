# Limit Dashboard

一个只保留 Medium 样式的 macOS 悬浮小应用，用来展示 ChatGPT Work 和 Codex 的每周使用限额。

功能：

- 无菜单栏图标
- 悬浮在其他窗口上方
- 拖动卡片即可移动位置
- 自动保存上次位置
- 每 60 秒读取一次本机 Codex 账户限额
- 右键卡片可以立即刷新或退出
- 鼠标悬浮时自动降低透明度并允许点击穿透
- 按住 Command（命令键）时恢复可拖动和右键操作

额度颜色：

- 41%–100%：绿色
- 11%–40%：黄色
- 0%–10%：红色

环形进度和中心额度数字会同步使用对应颜色。

应用通过本机已安装的 Codex 服务读取账户数据，不保存或复制登录凭据。使用前请确认 ChatGPT/Codex 已安装并保持登录状态。

## 设计规则

Limit Dashboard（限额仪表盘）采用只保留 Medium 样式的悬浮卡片，设计目标是让用户在桌面上快速读到“还剩多少”，同时尽量减少对后方内容的遮挡。

### 画布与容器

- 卡片尺寸固定为 180 × 108 pt，只维护 Medium 样式。
- 使用无边框悬浮窗口，连续圆角半径为 12 pt。
- 窗口背景透明，卡片自身不使用系统外阴影，避免出现矩形阴影、白边或额外边框。
- 卡片内边距为水平 12 pt、垂直 10 pt；所有内容都在圆角边界内裁切。
- 卡片背景从左上到右下使用深色渐变：`#121923` → `#0B1017`。
- 右上角保留低强度蓝色光晕，左下角保留低强度绿色光晕，用来增加层次，不影响文字阅读。

### 字体与层级

- 所有界面字体使用 Apple 系统字体 San Francisco。
- 状态标签和 Reset 信息使用 SF Mono，保持时间、百分比和状态文本的规整感。
- 顶部状态标签：8 pt 等宽字体，字距 0.7 pt。
- 主标题 `Weekly Limit`：12 pt，中等字重。
- 副标题 `7-day capacity · Plus`：8 pt，柔和灰蓝色。
- 中心额度数字：11 pt，中等字重，保持单行、水平和垂直居中。
- 中心 `left` 标签：6 pt，用于辅助说明，不抢夺数字焦点。
- 底部 Reset 信息：7 pt 等宽字体，左对齐。

### 颜色系统

| 色彩 | 用途 | 色值 |
| --- | --- | --- |
| 主文字 | 标题和中心额度数字的基础文字色 | `#F5F7FC` |
| 次级文字 | 副标题和 Reset 信息 | `#ABB5C7` |
| 弱化文字 | 顶部状态标签 | `#707F96` |
| 绿色状态 | 100%–41% 剩余额度 | `#8AE06B` |
| 黄色状态 | 40%–11% 剩余额度 | `#F2B84D` |
| 红色状态 | 10% 及以下剩余额度 | `#F06E66` |
| 未使用轨道 | 环形图未使用部分 | 白色 9% 透明度 |
| 分隔线 | 底部信息区分隔线 | 白色 12% 透明度 |

绿色、黄色和红色都采用略微降低饱和度的版本，确保在深色背景上足够醒目，同时避免刺眼。环形进度的已使用轨道与中心额度数字始终使用同一状态色，未使用轨道固定保持低对比度灰色，以保证数字和进度方向清晰可辨。

### 布局规则

- 顶部行由 6 pt 状态圆点、状态文本和右侧留白组成。
- 中部左侧是标题和副标题，右侧是 56 × 56 pt 环形图。
- 环形图线宽固定为 6 pt，进度从顶部开始顺时针绘制。
- 中心数字使用固定显示区域，避免 `%` 在不同额度下被裁切。
- 底部使用 1 pt 分隔线，Reset 信息始终左对齐。

### 交互规则

- 鼠标移入卡片时，窗口降低到 18% 不透明度，并开启鼠标事件穿透，后方桌面内容可以继续点击。
- 按住 Command（命令键）并将鼠标悬浮在卡片上时，恢复 100% 不透明度和完整鼠标交互。
- Command 状态下可以按住鼠标左键拖动卡片，也可以右键打开刷新和退出菜单。
- 松开 Command 后，卡片恢复鼠标穿透状态。
- 卡片位置自动保存，并在下次启动时恢复；窗口可跨桌面空间显示，不提供菜单栏入口。

### 数据与刷新

- 应用每 60 秒读取一次本机 Codex 账户限额。
- 额度来自本机 Codex 服务的账户和限额接口。
- 应用不保存、不复制登录凭据。
- 加载中或无法读取额度时，使用绿色状态色作为默认视觉状态，避免空数据造成突兀的红色告警。

### 构建与验收

- 当前构建面向 Apple 芯片 Mac 和 macOS 14 或更高版本。
- 使用 SwiftUI 绘制卡片，使用 AppKit 管理无边框悬浮窗口和桌面交互。
- 使用 `./Scripts/build-app.sh` 构建应用。
- 验收时需要确认四角没有白边或矩形阴影，百分比完整显示，三档额度颜色切换清晰，悬浮穿透和 Command 操作模式正常。

## 运行

双击同目录下的 `Limit Dashboard.app`。

如果需要重新编译，在终端执行：

```text
./Scripts/build-app.sh
```

当前构建面向 Apple 芯片 Mac。应用没有菜单栏入口，退出方式是右键卡片后选择 `Quit Limit Dashboard`。
